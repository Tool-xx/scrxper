Расширение для Chrome / Edge (Manifest V3, 111+).
Собирает верифицированные подписки и подписчиков из X (Twitter),
читает количество подписчиков, строит HTML-отчёт и отправляет в Telegram.

[скачать файлы] [github] [▶ видео-инструкция]

Файлы скачиваются напрямую из репозитория GitHub.

== ВИДЕО-ИНСТРУКЦИЯ ==

7 анимированных сцен: установка, Telegram, парсинг, фильтры, TAS (Grok), обновления. Проигрывается автоматически, по кругу.

Хотите управлять воспроизведением (пауза, перемотка, сцены) — откройте полный плеер.

== ВОЗМОЖНОСТИ ==

  • Только с галочкой — собираются исключительно верифицированные аккаунты
  • Год создания и число подписчиков — приходят сразу с API (те же запросы, что делает сам x.com), без обхода профилей
  • Фильтры — год создания (2020+ / 2020- / 2020-2022 / 2020), число подписчиков (та же синтаксис) и исключение аффилированных (бизнес/организации) аккаунтов — в обоих режимах
  • Один HTML-отчёт — тёмная тема, статистика, таблицы Подписки/Подписчики, фильтр, кнопка копирования
  • Тихий режим — парсинг идёт в фоновой вкладке, которая закрывается сама
  • Человеческое поведение — те же GraphQL-запросы, что у веб-приложения, случайные паузы, без бот-маркеров и следов расширения
  • Авто-обновление — раз в час тихо сверяет версию с репозиторием; при выходе новой версии показывает плашку с кнопкой скачивания
  • TAS-режим (Grok) — список верифицированных → OSINT-промт в Grok → посты в канал + случайный стикер
  • Обработка ошибок — логин-воллы, приватные профили, rate-limit, переименованные аккаунты, автоповторы

== КАК РАБОТАЕТ ==

[1] Обычный парсинг

  1. Вводите ссылку на профиль, токен бота, свой Telegram ID и (по желанию) фильтры: год создания, число подписчиков, исключение аффилированных.
  2. Расширение открывает фоновую вкладку и собирает x.com/<профиль>/following и /followers через те же GraphQL-операции, что и само приложение.
  3. Собираются только верифицированные аккаунты, прошедшие фильтры: имя, @username, галочка, био, год создания, число подписчиков.
  4. Если API-путь недоступен — автоматический фолбэк на скролл DOM.
  5. Собирается один общий HTML-отчёт и отправляется в Telegram.
  6. Фоновая вкладка закрывается сама.

[2] TAS-режим (Grok → канал)

  1. Вводите профиль, ID канала и токен бота.
  2. Расширение собирает только ссылки верифицированных аккаунтов (без био и подписчиков).
  3. Открывает x.com/i/grok и вставляет встроенный OSINT-промт со ссылками через запятую.
  4. Ждёт ответ Grok, нажимает «Copy text», захватывает текст через хук буфера обмена.
  5. Ответ делится на блоки {...} — каждый человек отдельным постом в канал (~1 сек).
  6. Через секунду после последнего поста отправляется случайный стикер из пака CrazyEvilBro.

Весь вывод Grok — на русском языке. Промт фильтрует по 11 критериям (популярность, финансы, крипто, карьера, личность, соц. активность, сеть, уникальность, информационная плотность, текущая активность, сигнал/шум) и строит подробные профили с анти-галлюцинационными метками.

== УСТАНОВКА ==

  1. Скачайте расширение — нажмите [скачать .zip] и распакуйте в постоянную папку. В папке обязательно должен быть файл manifest.json.
  2. Загрузите в браузер — откройте chrome://extensions (или edge://extensions), включите Developer mode, нажмите Load unpacked и выберите папку.
  3. Создайте Telegram-бота — в @BotFather выполните /newbot и получите токен вида 123456789:AAH.... Узнайте свой Telegram ID через @userinfobot и напишите боту /start (бот не сможет писать первым).
  4. Запустите — откройте x.com, войдите в аккаунт, внизу справа появится панель ScrXper. Введите данные и нажмите Start (или Test для проверки бота/токена).

== ЧАСТЫЕ ВОПРОСЫ ==

«Telegram is unreachable: Unauthorized»
Неверный токен бота. Создайте нового бота через @BotFather и вставьте токен заново.
«Forbidden: bot was blocked by the user»
Вы ни разу не писали боту. Откройте чат с ботом и нажмите Start.
«chat not found»
Неверный Telegram ID. Проверьте через @userinfobot.
«Could not load the following/followers list»
Не вошли в X, профиль приватный/заблокирован, или X недоступен. Войдите и выберите публичный профиль.
«X rate limit»
X ограничил запросы. Подождите 10–20 минут и запустите снова.
TAS: «could not send post … to the channel»
Неверный ID канала или бот не является администратором. Добавьте бота админом.
TAS: «could not find the Grok input»
Не вошли в X или Grok недоступен. Откройте x.com/i/grok вручную.
TAS: «the Grok answer does not contain {...} blocks»
Grok проигнорировал формат. Проверьте ответ в Grok; промт — константа TAS_PROMPT в content.js.
Браузер блокирует всплывающее окно
Разрешите всплывающие окна для x.com в настройках браузера и нажмите Start.
Панель не появляется
Обновите страницу x.com. Если не помогло — перезагрузите расширение (chrome://extensions → ↻).
